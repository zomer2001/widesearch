资料研究台 · 本机演示版

打开方式
1. 双击本目录“启动资料研究台.command”。
2. 浏览器访问 http://127.0.0.1:3000 。服务只在本机监听。
3. 关闭启动窗口或按 Ctrl+C 停止服务。已保存的任务不会丢失。

主要操作
左侧填写研究问题并选择资料；右侧查看研究结果、来源与证据、执行过程及研究图谱。
在窄窗口中点击“新建任务与历史”展开左侧任务区。
图谱支持任务/证据两种视图、节点详情、缩放和平移，以及全屏展开。
本地资料图中的“阅读片段”表示实际读取记录，并不表示已经过独立事实核验。

四种模型
OpenAI API：在设置中填写密钥，默认模型 GPT-4o；可点击“保存并测试”检查连接。
DeepSeek API：在右上角设置中填写 API 密钥及模型名，再检查连接。
Ollama：复用本机服务。已配置 research-qwen3-32k:latest，服务实测窗口32K；旧16K配置仍保留。
CLI · 6-luna：使用已登录的本机 Codex CLI，模型为 gpt-6-luna；模型推理需要联网。
模型在任务开始时固定，正在运行的任务不能切换；续问沿用当前研究的模型与窗口。
OpenAI、DeepSeek 与 CLI 会向所选模型服务发送该任务使用的内容；Ollama 在本机推理。
当前 OpenAI 回答整段返回，任务进度照常更新；完成后仍保留原文引用和历史记录。

任务资料长期保存
研究结束（包括失败或停止）时，已成功保存的网页正文会自动归入“研究网页资料”库。
左侧“任务资料库”可直接进入，查看正文、原件副本和来源，或使用已有删除功能。
相同正文跨任务去重并保留来源任务关联；正文变化保留为不同内容版本。
资料库保存的是研究中实际保存的网页正文副本，搜索摘要和抓取失败页面不会冒充正文入库。
从资料库删除正文后，历史任务重新整理不会恢复该资料；原任务归档记录单独保留。
删除整个“研究网页资料”库会停止自动向该库归档，历史整理也不会重新创建该库。

联网检索
右上角“工作台设置 → 联网检索 → 网页读取方式”可选自动、Crawl4AI 浏览器抓取、Trafilatura 正文提取、轻量直读或 Jina 外部服务。
推荐自动：先在本机提取正文，短文本或读取失败时再渲染网页；不会自动调用 Jina。
“试抓网页”可粘贴公开网址直接预览，显示实际抓取方式、时间、字符数与缓存状态；无需模型或搜索密钥。
从网址导入网页也会使用所选方式，导入作业保存开始时的配置，后续更改设置不影响已有作业。
选择“网页”或“混合”时，可使用“免密钥搜索 · DDGS”，不需要搜索 API 密钥。
搜索服务负责找到网址，网页读取方式（Crawl4AI/Trafilatura 等）负责提取正文。
设置中可先点“测试搜索”确认返回真实链接，再保存配置。
Serper 与 Tavily 仍需各自密钥；模型连接与搜索服务是两项独立配置。
只使用本地资料不需要搜索密钥。

可选研究增强
当前为试验功能：代码和界面已接入，完整多步实测尚未通过，演示基础流程时请保持关闭。
左侧展开“可选研究增强”，可分别开启“证据适用性与修订”和“目标与采集经验”。
默认全部关闭。开启后本地任务进入多步研究，通常比直接问答耗时更长。
右侧“增强记录”区分已启用和真实触发，并显示当前研究累计记录。
续问保持原模块组合；更换模块组合请新建任务。
“创新模块演示 · 虚构任职资料”库内有两份明确标注为虚构的有效期公告，可用于观察时间核验。
当前界面支持查看修订记录；人工确认修订按钮尚未开放。

网页抓取依赖
当前已安装 Crawl4AI 0.9.5、Trafilatura 2.3.1 与 Chromium。
已补充 DDGS 9.16.1 免密钥搜索；新任务使用保存的搜索服务，不再回退到旧的内部搜索配置。
重新安装：.venv/bin/python -m pip install -r requirements-crawling.txt
安装浏览器：.venv/bin/python -m playwright install chromium
重复实测：PYTHONPATH=. .venv/bin/python scripts/verify_crawling.py
data/crawling-verification.json 保存普通页面、动态页面和自动切换的验证结果。
data/web-search-verification.json 保存正式搜索工具找到链接并读取正文的实测；未调用模型。
data/crawler-runtime/ 保存本机抓取运行数据，data/page_cache/ 保存按抓取方式区分的正文与 HTML 缓存。
