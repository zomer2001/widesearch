# 资料研究台：前端设计与操作约定

本机个人研究工作台。首页使用两栏结构，面向“提出问题、选择资料、查看结果”的实际研究过程。

## 页面结构

- 顶部：名称、DeepSeek API / Ollama / CLI · 6-luna 三个模型入口、设置。
- 左栏：问题输入、网页/本地/混合来源选择、研究深度、开始/停止、示例资料、最近研究。
- 右栏：首次使用引导；开始研究后显示真实运行状态、结果、来源与证据、执行过程和图谱。
- 手机：顶部保留模型入口，任务面板可展开，结果区保持单栏阅读。

当前任务运行时禁止切换引擎或修改模型配置。引擎切换成功后保存本机默认设置，开始研究时仍显式发送本轮引擎。

## 视觉

使用系统字体，不依赖远程字体。白色侧栏与浅灰绿工作区、墨绿正文和绿色操作按钮。状态颜色只表示真实任务或连接状态。

- 页面底色：`#f7f8f6`
- 操作主色：`#235d49`
- 正文字色：`#20352e`
- 边框：`#e1e6e1`
- 侧栏宽度：桌面 330px，大屏 360px，小屏 300px
- 主区内容宽度：约 1070–1140px
- 手机断点：760px

界面样式集中在 `src/app/workbench.css`，共享表格、证据和资料库组件继续使用基础样式变量。

## 结果真实性

进度、用量、证据数量、来源数量均来自运行状态与事件。没有数据时明确显示等待或暂无记录，不生成假进度。

本地问答未生成结构化证据时，来源页展示实际读取事件中的资料片段与原文入口。历史记录通过真实持久化会话恢复，不模拟时间回放。

首页示例文件是明确标注为虚构的项目简报，仅用于功能体验。点击载入后走正常文件上传、解析与检索流程；最终回答始终由所选模型实时生成。

## 验证

- `npm test`：请求、状态流、来源恢复、引用、覆盖表与交互回归。
- `./node_modules/.bin/tsc --noEmit`：完整类型检查。
- `NEXT_TELEMETRY_DISABLED=1 NEXT_PUBLIC_API_URL= npm run build -- --webpack`：本地生产构建。

HTTP 和 WebSocket 默认经前端同源入口转发至本机后端。密钥仅写入本机后端配置，界面不回显已有密钥。
